# Provision 0.155.1

Reviewed against Codex CLI 0.155.1, with the existing Codex 0.144.0 minimum.

- Keeps selected reasoning effort effective across Astra configuration updates
  and observed incremental response chains.
- Shows backend denial and unknown included-usage availability independently of
  quota percentages, and preserves separate reserve quota aliases.
- Follows worktree moves without losing session identity, profile pins, terminal
  controls, or previously observed native history.
- Invalidates account caches on credential changes and rejects delayed reads and
  temporary app-server credential imports from an older login.
- Delivers HTTP stream events promptly, including compaction progress.
- Refreshes fallback model choices and explains saved models absent from the
  current catalog.
- Includes Coverage 7.16.1 (#19) and Ruff 0.16.7 (#20).

Validation: 304 Python tests; 72 UI regression checks; Ruff lint and formatting;
strict type checks for 11 extracted modules; isolated Codex app-server smoke;
wheel and source distribution build, package metadata checks, and clean install.
Local Python validation used Python 3.12; CI covers 3.11, 3.12, and 3.13.

See [the compatibility review](https://github.com/jeremydixon22/provision/blob/Provision-v0.155.1/docs/codex-0.155.1-compatibility.md) for protocol
coverage and limits, including hidden server-side history, native questions, and
compressed rollouts. Restart the Provision daemon after upgrading to activate
the compatibility changes.
