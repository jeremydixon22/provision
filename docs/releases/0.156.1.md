# Provision 0.156.1

Reviewed against Codex CLI 0.156.1. The Codex 0.144.0 minimum remains.

- Restores Codex 0.156.1 TUI bootstrap by serving its workspace backend over
  private, loopback-only HTTPS. Provision supplies the CA to launched Codex
  processes without changing system trust or profile routing. Earlier Codex
  versions retain the HTTP path. The ten-year server certificate renews under
  the same private CA when fewer than 120 days remain, with checks at startup
  and hourly while running. The CA is valid for 20 years and is renewed at
  daemon startup if fewer than 120 days remain.
- Reduces repeated quota reads with a five-minute ordinary cache and error
  backoff. Manual refresh still fetches current data.
- Refreshes included-usage permission separately from percentages; after five
  minutes without a permission result, the dashboard displays unknown
  availability instead of presenting an old denial or approval as current.
- Keeps account caches across same-account token rotation and prevents an older
  temporary app-server credential copy from overwriting a newer refresh.
- Adds GPT-6-Sol and GPT-6-Luna to the degraded-mode model picker.

The reported `Included usage blocked` state was stale when investigated: a fresh
backend read and app-server permission check showed usage available. The cause
of the original backend denial was not established. The previous HTTP override
was independently confirmed to fail Codex 0.156.1 `account/read` bootstrap.

Validation: 325 Python tests; 72 UI checks; Ruff lint and formatting; strict
mypy checks for 12 modules; wheel and source distribution build with metadata
checks; clean package install; real
Codex 0.156.1 `account/read` against an isolated Provision HTTPS listener. CI
covers Python 3.11, 3.12, and 3.13.

See [the compatibility and quota review](https://github.com/jeremydixon22/provision/blob/Provision-v0.156.1/docs/codex-0.156.1-quota-review.md)
for protocol coverage and limits. Restart Provision after upgrading; the
launcher detects and replaces the older daemon protocol automatically.
